看清你实际装了什么。

skill 会堆积在全局目录、项目目录和十几个 agent 专属位置里；它们互相遮蔽，也会与锁文件 记录的版本脱节。SkillCat 把这些全部读一遍，展示真实状态。

它做什么，以及该信到什么程度。

功能做什么来源

清单覆盖 90+ 已知 agent

扫描全局、项目级与自定义目录，报告每个 skill 的来源、锁元数据，以及真实的链接状态： 符号链接、悬空，或副本漂移。

core

触发画像正向与负向

从 when_to_use、dispatch_intent、description 和 「When to Use」小节中提取每个 skill 的触发条件。你可以在 sidecar 里手工标注触发词， skill 文件永远不会被改写。

core

分析确定性与启发式

确定性规则读取磁盘事实：悬空链接、锁记录缺失、副本漂移、本地改动、跨作用域遮蔽与 来源冲突。启发式则提示触发词重叠、负向矛盾与正文重复，并给出置信度与造成命中的共享词。

rules

AI 评估可选，自带密钥

用你自己的模型为每个 skill 评分，并判定预筛选出的重复与冲突候选对。结果带签名保存， 界面据此提示评估是否已经过期。

ai

项目自动发现

根据扫描根下的 agent 标记发现项目，把常回访的钉住。注册表只存路径，删除条目不会 删除任何文件。

core

远程搜索skills.sh 榜单

浏览公共索引与全部时间、趋势、热门三个榜单，安装前先读一遍 SKILL.md，然后直接装进 当前作用域。

online

安全操作唯一安装路径

每次变更都把进度流式展示在抽屉里，有确认步骤，也可以取消。写入一律委托官方 skills CLI，因此只有一条安装路径，而不是两条。

cli

扫描、分析、执行。

三步，其中只有第三步可能改动磁盘上的内容。

01

扫描

读取全局与项目锁文件，枚举 canonical 目录、每一个已知 agent 目录和你的自定义目录， 再对每个 skill 的内容做哈希。

02

分析

对全部记录运行规则引擎，提取触发画像，在开销低的地方计算相似度，并合并你保存的标注。 整个过程不会向 skill 写回任何内容。

03

执行

安装、更新或卸载 —— 每一步都经过确认、流式展示、可取消，并且由官方 skills CLI 执行，而不是由 SkillCat 自己执行。

读取

本地且离线

扫描只使用文件系统与锁文件，清点与分析 skill 不需要任何网络请求。

写入

委托给 CLI

每一次变更都走官方 skills CLI。SkillCat 不会成为第二个事实来源， 也不会背着你改动文件。

值得问的问题。

Q1 它和直接用 skills CLI 有什么区别？

CLI 负责安装 skill。SkillCat 让你看清已经装好的东西处于什么状态：它读取 CLI 与 各个 agent 写到磁盘上的内容，解释每个 skill，并在问题爆发前把具体问题指出来。

Q2 需要 API 密钥吗？

不需要。清单、触发画像与规则引擎都不依赖模型。只有开启可选的 AI 评估时才需要密钥。

Q3 它认识哪些 agent？

超过 90 个已知 agent 目录，包括 Claude Code、Codex、Cursor、OpenCode、Gemini CLI、 Windsurf 与 Trae，也可以自己添加 skill 目录。

Q4 它会改动我的 skill 吗？

不会悄悄改。扫描是只读的，标注保存在配置目录的 sidecar 文件里。对 skill 目录的 任何改动都要经过官方 skills CLI，并带确认步骤。

Q5 能离线使用吗？

可以。扫描与分析只用文件系统与锁文件。联网只用于可选的远程搜索、榜单与 AI 评估。

Q6 它是免费的吗？

免费。SkillCat 基于 MIT 许可开源，没有账号、没有订阅，也没有遥测。

Q7 运行它需要什么环境？

macOS 版是自包含的：内置 skills CLI，无需安装 Node.js。Windows 需要 Node.js 22 或更高版本。
